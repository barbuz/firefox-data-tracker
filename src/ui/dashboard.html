Data Usage Tracker

Counts the bytes each response actually delivers, including chunked and streamed responses that have no Content-Length. Requires an extra permission, and decoded sizes are larger than the compressed sizes on the wire, so both are shown side by side. Records one line per request and per error (time, site, serving host, type, wire bytes, decoded bytes, and the error reason), so the wire and decoded numbers can be compared request by request. Stored locally, capped per day, and removed with the retention window. Off by default because it grows with request volume.
